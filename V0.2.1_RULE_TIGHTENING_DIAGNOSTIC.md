# TrialDiff v0.2.1 Rule Tightening Diagnostic

Status: diagnostic rule revision; not re-certified
Date: 2026-06-18

This document records the first v0.2.1 classifier tightening pass after the
failed v0.2 severity calibration and `V0.2.1_DISAGREEMENT_ANALYSIS.md`.

It is not a calibration pass. It uses the already-reviewed 25-study corpus only
to verify that the revised rules move in the intended direction. Certification
still requires fresh records.

## Changes

Implemented rule changes:

1. Disabled broad timing escalation.
   - Late timing no longer automatically escalates high categories to critical.

2. Lowered broad structural rule defaults from critical to high.
   - `design_info_change`
   - `phase_change`
   - `arms_or_interventions_change`
   - `terminal_status_change`

3. Preserved critical status for specific high-stakes value signals.
   - empty or removed `whyStopped`
   - enrollment zeroed
   - serious adverse event removal
   - primary outcome changes that are not suppressed as results reconciliation

4. Added results-reconciliation suppression.
   - outcome rules are suppressed when outcome edits occur inside patches that
     set `/hasResults` true or add/replace `/resultsSection`;
   - suppressed reconciliation-only outcome edits emit a low
     `results_reconciliation` signal rather than disappearing entirely;
   - this implements the v0.2 rubric presumption that co-incident results
     posting/reconciliation should not be treated as prospective outcome
     amendment without independent substantive evidence.

5. Down-tiered timeline shifts.
   - 90-365 day timeline shifts now classify as medium;
   - major slips over 365 days classify as high only when the FROM-version
     context is late recruitment or post-recruitment;
   - major slips during early recruitment remain medium pending the unresolved
     magnitude-boundary question;
   - earlier date movements are down-weighted.

## Interpretation

This is the intended directional movement:

- critical is now much rarer;
- broad structural and terminal-status changes no longer become critical by
  default;
- timeline-significant shifts no longer dominate the high tier;
- results-reconciliation patches no longer automatically become critical
  outcome-change records, but remain visible as low reconciliation records.

The result is still not certified. The same 25-study corpus and the same
unblinded diagnostic evidence were used to design these changes. This pass only
shows that the rule changes address the observed failure modes mechanically.

## Still Open

Unresolved rubric/rule boundaries:

- whether very large timeline slips during active recruitment should become high
  by magnitude alone;
- whether routine/exploratory secondary-outcome additions before completion are
  high or medium;
- how to separate historical completed-record backfill from post-completion
  substantive amendment;
- whether the remaining primary-outcome critical records survive fresh blinded
  review.
