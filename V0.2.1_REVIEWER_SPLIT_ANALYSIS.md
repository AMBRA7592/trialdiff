## Interpretation

The split is concentrated where it matters most: critical primary-outcome records and a smaller set of high-plus records where R1 treats the change as high-or-above and R2 downgrades it. The evidence does not support immediate v0.2.2 rule tightening, because that would tune against a failed certification sample before resolving whether the stricter reviewer is applying the rubric correctly.

If third-reviewer adjudication over the full critical stratum tracks Reviewer 1's downgrade rate, Reviewer 2 should be treated as over-strict and a future cycle can target the remaining R1-level over-fire. If third-reviewer adjudication tracks Reviewer 2's downgrade rate, the critical tier remains structurally too aggressive and certified severity should be decoupled from the evidence-record primitive unless a materially different severity design is adopted. Either way, this v0.2.1 sample remains a failed certification sample.

## Stop Rule

No v0.2.2 rule changes should be made from this sample until the full-critical-stratum adjudication result is recorded. The adjudication does not reopen the v0.2.1 gate; it only decides whether a future cycle should target R1-level over-fire or whether certified upper-tier severity should be abandoned in the current design.
